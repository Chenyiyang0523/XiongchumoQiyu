# 发布门禁

任何一项失败都应停止发布。

## 安全与隐私

- [ ] 已撤销并轮换所有曾进入源码、编译缓存、APK、ZIP 或安装包的旧凭据。
- [x] `python3 tools/check_project.py` 通过，无密钥、TLS 降级或开发机绝对路径。
- [ ] 客户端不携带模型服务商长期密钥；云端只连接受控 HTTPS 代理。
- [x] 默认离线，云端故事必须由玩家/监护人显式开启。
- [ ] 隐私政策、监护人同意、数据删除和服务端日志保留策略已完成评审。
- [ ] Android 权限只保留真实功能需要的最小集合，并关闭不必要的备份。

## 游戏正确性

- [x] `python3 tools/test_core_logic.py` 通过。
- [x] `tools/run_renpy_lint.sh` 零错误、零缺失资源。
- [x] `tools/run_visual_qa.sh` 通过，并人工复核账户、选角、设置和 QTE 截图。
- [x] `tools/run_build_verify.sh` 通过，展开后的 PC 构建无源码或风险残留。
- [ ] 新账户、正式账户切换、游客清理、删除账户和四页存档隔离均经实机验证。
- [ ] 断网、超时、空响应、损坏响应和连续快速重开都能安全回退。
- [ ] 每次选择只结算一次；完成同一局不会重复累计统计或结局。
- [ ] Windows、macOS 与目标 Android 设备完成从开场到结局的冒烟测试。

## 体验与可访问性

- [ ] 触屏、鼠标与键盘都能完成选择、QTE、返回、保存和加载。
- [ ] 1280×720 与 1920×1080 下无文本溢出或遮挡。
- [ ] 拼音、自读、QTE 轻松完成和长列表滚动均实机可用。
- [ ] 儿童关键按钮尺寸和文字对比度通过人工检查。
- [ ] 技术错误、服务商名称和原始响应不会直接展示给儿童。

## 资产与产物

- [x] 六张背景均存在且格式真实；发行包内无候选图、棋盘格占位图或重复背景。
- [ ] 已确认角色、名称、音乐、字体、图片及衍生内容的发布授权与署名要求。
- [x] 构建物不含 `archive/`、`.local/`、`assets-source/`、`python-packages/`、缓存、存档或日志。
- [ ] 版本号、包名、图标、签名、更新渠道与安装器信息一致。
- [ ] 对最终 APK/ZIP/RPA 再做一次凭据和绝对路径扫描。
