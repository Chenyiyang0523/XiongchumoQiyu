## 功能优化

- 四个本地篇章：森林古地图、森林运动会、风雨后的家园、森林美食节。
- 每篇有三条开局路线，进入不同地点和任务，随后汇入该篇章主线；不同时长选取不同数量的中段事件，不循环复用四个场景模板。
- 观察、行动、合作有不同属性反馈；自定义行动通过关键词归入对应方案，并明确告知处理方式。
- 儿童模式提供简明探索；青少年模式增加方向、长度、材料分配或比例推理，答案会被验证，答错也会给出解释并继续。
- 亲子模式增加选择理由与替代方案讨论，结果写入本局报告。
- 提示神器提供当前任务提示；心愿支线提供巧手、探索、友谊三种任务及对应纪念物；指定结局支持大团圆、反转与留白。
- 每局包含行动挑战和相关百科；挑战先等待准备，再计时，支持点击、空格和轻松完成，超时不会阻断主线。
- 常驻显示回合进度，主题可直接从四个按钮选择。

本地库是有限的手写篇章。自由情景按关键词匹配，未匹配时进入寻宝篇；自由行动和心愿也采用预设分类，不是任意文本理解。云端接口仍保留，但此次未配置或交付外部服务端。
