# 2.0 技术验收与候选版交付

日期：2026-10-03。版本：**2.0.0-alpha.2**。统一互动绘本系统、本地 GLM 接入、素材及部署环境已经实现；真实模型 **60 / 60 案例技术复验通过**，三个平台的实际安装包已通过原生测试。**人工逐本检查与 20 组盲评按用户决定保持待完成，正式发布门禁保持关闭。** 自动审校和自动化试玩不等同于人工质量验收。

## 实现范围

四个既有主题和自定义主题共享蓝图、世界状态、事件、页面和行动协议。三候选规划、最近十本特征比较、动态行动和独立审校共用一条管线，没有篇章专属的回合执行表。人物特长与弱点进入实际行动。

状态账本使用稳定 ID、初始蓝图、追加事件、事实来源和页级快照。程序验证道具归属、制作消耗、人物在场、任务依赖、奖励去重、素材和动作条件。新承诺带事实条件，兑现前验证实际结果；模型协议明确 false 为尚未兑现、true 为实事已完成，避免把口头答应误当成完成；旧记录保持兼容，不补造历史。

客户端提供五类互动、自由表达、歧义确认、亲子理由、目标、线索、背包、翻页、回看和账户书架。页内操作本地预演，翻页统一提交。作品保存实际选择和共享结局，支持含字体、图片及数据的离线 HTML。

FastAPI、SQLite WAL 和单工作进程持久队列负责类型化请求、幂等、版本冲突和事务提交。断网保留原行动；截断、错误 JSON、审校失败不提交，不自动切换模拟内容。旧账户、成就、图鉴保留，新旧进行中存档隔离。协议见 [实现说明](IMPLEMENTATION.md)、[OpenAPI](openapi.json)、[GLM 接入](LOCAL_GLM.md)。

## 真实评测和限制

定义为六类结构 × 两档年龄 × 五主题，共 **60 案例，其中 36 个新主题**，标准 12 页。最终 60 本全部通过账本重放、全部页快照、**1618 个可用行动反事实**、有效互动、后续回应、人物特征、必要任务与承诺、长度及素材核验。59 本为 12 页，1 本使用两页收束为 14 页；43 本实际使用三类互动、13 本四类、4 本五类。这是可执行事实检查，趣味性及未检出的语义矛盾仍须人工审阅。

模型使用本机 Claude Code 配置中的同一 GLM 账户。隔离 CLI 连通实际验证成功，长规划曾超时；完整故事采用 GLM Coding 原生结构化接口，**不能称为全部经 CLI 子进程运行**。长期凭据未写入客户端、Git、镜像或作品。

第一次 60 案例为 **23 完成、36 失败、1 待续**。它暴露了修订丢失行动、场景交付、消耗物品复用、承诺收束、套餐限流和网络问题，已增加规则及恢复机制。恢复保留原请求；预算耗尽或待续作品保留原件，另建明确编号的新故事尝试。共 77 次故事尝试，保留 16 本未完成原件和 1 本待续原件。最终选择每个案例第一个完成的作品，保留全部失败、重试、源版本及用量，不能将最终结果写成首次全部成功。

[验收汇总](acceptance-evaluation/summary.json) 及同目录保留初次结果、全部尝试、恢复历史、源版本和空白人工表。完整 JSON、HTML、数据库在本地和交付档案中；Git 不保存逐本大文件。生成期间经历多个修复版本，全部源版本记录保留；最终对所选作品和历史快照重新验证，**不是从同一最终提交重新生成的 60 本**。近期恢复时本地模型别名曾变为 glm-5.3-flash，发现后中止未提交生成并固定 glm-5.3；9 次调用或占位仍计入全部历史。较早探索批次 [live-evaluation](live-evaluation/summary.json) 标记中止，不混入最终集。

每轮默认提案与审校，最多一次修订及复检；**每个生成尝试最多四次调用，显式失败重试另外计量**。默认每本 120 次调用 / 700000 token。调用后才知道实际 token，最后一次可能跨过阈值，下一调用会暂停并保留状态。宿主进程共享两个请求槽；容器是独立锁域。网络失败保留请求，不执行内容修订。

60 案例的全部故事尝试记录 **3185 次调用 / 占位、41109847 已知 token、124 次用量未知、639 次修订**。最终所选作品调用中位数 39 次、已知 token 中位数 483777、累计模型等待中位数 414.6 秒；等待 P95 为 981.4 秒。这是整本的请求等待累计，含重试，不包含阅读时长，也不等于并发运行的墙钟时间。[详细测量](acceptance-evaluation/technical-statistics.json)。容器及原生联网 QA 的独立调用记录见 [补充计量](native-live-usage.json)。GLM Coding 未提供实际账单，**费用未知，不是零**；正式成本验收需要独立账单或部署费率。并发模型等待总和不等于单本玩家耗时。
