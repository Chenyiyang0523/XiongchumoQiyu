# 2.0 候选版验收报告

日期：2026-10-02。版本：**2.0.0-alpha.1**。结论：统一系统已实现并提供可部署服务和客户端候选包；**正式发布门禁未通过**。不能据此声称真实模型故事质量、Windows / Linux 实机或盲评分数已达标。

## 平台验证

Mac 使用候选 ZIP 中的应用，不依赖 SDK 的 Python。注入的 QA 脚本只存在隔离解压目录；候选 ZIP 未被修改。应用未签名、公证，首版不声称具备正式分发签名条件。

Windows 合包内运行时与资源完成构建检查，**没有 Windows 主机实测**。

Linux 已实际启动最终合包内的 Linux 运行时，复现退出139；此前候选还分别尝试了不同渲染器，环境为 Docker Debian bookworm / x86_64 的 Rosetta 模拟、Xvfb。GL2 llvmpipe、GL2 softpipe、GLES2 和 SW 均在首次图形初始化附近退出139，尚未进入玩法。**Linux 验证失败，未认定故障必然来自游戏或模拟环境**，需要在真实 Linux 桌面复验并解决后才可放行。见 [平台记录](platforms.json) 和 [最终 Linux 日志](package-qa/linux-current.txt)。

## 尚未满足的验收要求

1. **真实模型 60 本为 0**：当前未提供有效 `XCMQY_LLM_ENDPOINT / MODEL / KEY` 配置。真实评测入口明确返回配置缺失；没有用模拟服务填补结果。实际 token、费用、修订比例与等待时间尚无真实测量。
2. **逐本人工检查未执行**：人工表保留空白，未处理关键矛盾 / 漏任务 / 图文冲突的真实结论未知。
3. **20 组同主题盲评未执行**：匿名 A/B 准备、40 份评分与解盲工具已实现；没有虚构旧版对照、审阅者或平均4分。
4. **Windows 实测和 Linux 成功试玩未完成**，无法宣称三平台全部跑通。
5. **真实体验质量仍待验证**：候选筛选、语义审校及动态自由行动已经接线，但模拟故事主要用于故障和状态回归，不能证明内容多样性、趣味性与 LLM 稳定性。

[机器发布门禁](release-gate.json) 当前明确为 `formal_release_eligible=false`。补齐配置后可恢复同一个评测目录；每本人工检查、20组四维均分至少4、全部平台实际包通过，才进入正式发布。预算 / 超时暂停保留进度，不强行生成结局。

## 交付路径

`dist/2.0.0-alpha.1-final/` 包含 Mac / PC 候选 ZIP、服务部署 ZIP、原美术与提示档案、一个明确标记的模拟离线绘本示例及 SHA256SUMS。模拟评测 60 份作品 JSON 和自包含 HTML 保留在本地 `docs/v2/mock-evaluation/`，完整逐本 JSON、HTML 与数据库不进入 Git；Git 保留评测定义、结果与一份样本。

素材生成使用内置 imagegen；规范、精确提示、参考路径、最终文件与归档源记录保留在 [素材来源目录](../../assets-source/v2/)。运行时不使用生成 API。源图转 WebP 只改变无损容器，不缩放、不修图、不改透明通道。
