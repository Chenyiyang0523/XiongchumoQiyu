### **任务描述：修复背景显示为路径字符串（'bg/b...）的 Bug**

**问题反馈：**
目前在测试中，仅在加载页面会出现巨大的 **“ 'bg/b ”** 黑色/灰色占位文字（见截图）。

**原因分析（请 AI 检查）：**
这通常意味着 `scene` 指令接收到了一个无法识别的图片名称或错误的路径字符串。可能的原因包括：
1.  **字符串截断：** 解析 DeepSeek 返回的 JSON 时，`bg` 字段的提取可能出现了索引错误（例如只取了前几个字符）。
2.  **路径拼接冗余：** 代码中可能手动添加了 `"bg/"` 前缀，而 JSON 返回的字段里也带了 `"bg/"`，导致路径变成了 `bg/bg/filename`，从而失效。
3.  **未定义资源：** Ren'Py 找不到对应的图片，所以把路径字符串当作文字渲染了。
4.  **引号嵌套问题：** 变量里可能意外包含了多余的引号（如 `"'bg/bridge'"`），导致 Ren'Py 识别失败。

**修复要求：**

2.  **路径清洗逻辑：** 
    *   确保 `bg` 变量在传递给 `scene` 指令前，已经去除了多余的引号和空格。
    *   检查是否重复添加了文件夹前缀。
3.  **增加占位符保护（Fallback）：** 
    *   如果请求的图片文件不存在，**严禁**让 Ren'Py 渲染路径文字。

4.  **检查自动索引表：** 检查之前生成的 `BG_ASSETS` 映射表，确保里面的文件名与实际文件夹中的文件完全匹配（注意扩展名 .jpg / .png / .webp 的区别）。
